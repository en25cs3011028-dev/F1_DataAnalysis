
# F1 Race Intelligence Dashboard

An interactive Tableau workbook and analytical dataset designed to analyze Formula 1 racing performance, tyre strategies, and race dynamics.

## 📌 Project Overview
The **F1 Race Intelligence Dashboard** provides detailed visualization and data-driven insights into Formula 1 racing metrics. This project leverages historical and telemetry-based race data to track driver performance, pit stop efficiency, and strategy effectiveness across different Grand Prix events.
